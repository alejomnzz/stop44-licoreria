# 🍾 Stop 44 — Inventario y Ventas

App para la licorería **Stop 44**: inventario, ventas del día, resumen del negocio y cuentas de usuario (administrador y vendedor).

- **Backend:** Python + FastAPI + SQLite
- **Frontend:** HTML, CSS y JavaScript
- **App:** se instala en el celular como PWA
